常见问题

1. 如何配对连接我的 Harness 实例？

1) 在电脑上安装 Harness 插件 @jiuyang911/dsh-mobile-extras（官方已内置远程接入能力，本插件补充移动端所需端点）；
2) 在 $DSH_HOME/cordis.patch.yml 中配置插件并指定中继地址 wss://relay.lobsternetwork.top/tunnel，然后运行 dsh web；
3) 在连接页点击「扫一扫配对二维码」，扫描电脑端展示的配对二维码（dsht://pair?i=…&c=… 格式）；
4) 或手动输入 9 位实例码 + 6 位配对码完成连接。

2. 无法连接 / 显示离线？

· 确认电脑上的 dsh web 正在运行，且已安装并启用 @jiuyang911/dsh-mobile-extras 插件；
· 确认电脑可以访问外网（中继服务需要出站连接）；
· 配对码有效期 15 分钟，过期请重新生成；
· 检查手机与电脑是否处于不同网络（本应用设计为跨网络远程连接）。

3. AI 回复不显示？

请先确认会话处于「运行中」状态。如果长时间无回复，尝试：
· 停止当前会话后重新发送；
· 在模型栏切换其他模型；
· 检查电脑端 Harness 是否正常出词。

4. 如何升级到 Pro / 恢复购买？

· iOS：在「设置 → DSH Mobile Pro」页面选择月付或年付订阅，通过 Apple 完成支付；
· 换机恢复：同 Apple ID 登录后，在 Pro 页面点击「恢复购买」；
· 激活码：在爱发电等渠道购买后，在 Pro 页面输入激活码即可激活。

5. 订阅如何取消？

iOS 用户可在「设置 → 你的 Apple ID → 订阅」中管理或取消自动续订。取消后 Pro 功能将在当前订阅周期结束后停用。

隐私与安全

DSH Mobile 通过自建中继服务连接你自己的 Harness 实例。你的对话与数据始终存储在你自己的设备与 Harness 服务器上，App 与中继服务不存储、不解析任何对话内容。详见隐私政策。
